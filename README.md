
# Oracle Apex - Kamban

Kamban application created in Oracle Apex
## Installation

Login into Oracle Apex

```bash
  Go to Application Builder Page
  Click "Import"
  Upload the application file
  ensure "Application, Page or Component Export is selected
  Click next
  Select your import preferences and click next
```
## Tools used

- Custom CSS
- Custom JavaScript
- Drag and Drop
- Dynamic content Region
- PL/SQL script for page content generation
- Dynamic Actions
- Processing items
- modal pages
